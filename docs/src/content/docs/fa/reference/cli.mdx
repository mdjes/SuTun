---
title: دستورهای ترمینال
description: همهٔ دستورهای sutun، دسته‌بندی‌شده بر اساس کاربرد.
---

اگر `sutun` را بدون هیچ آرگومانی اجرا کنید، منوی تعاملی ترمینال باز می‌شود. همهٔ دستورهای زیر
به‌تنهایی هم کار می‌کنند و برای اسکریپت‌نویسی مناسب‌اند. بیشترشان سیستم را تغییر می‌دهند، پس آن‌ها
را با `root` یا `sudo` اجرا کنید.

:::tip
مدیریت روزمرهٔ مش در پنل وب انجام می‌شود. ترمینال برای راه‌اندازی است، و برای برگشتن به پنل
وقتی مشکلی پیش آمده.
:::

## دسترسی به پنل

| دستور | کاری که انجام می‌دهد |
| :--- | :--- |
| `sutun token` | یک لینک ورود یک‌بارمصرف تازه می‌سازد که ۶۰ دقیقه اعتبار دارد. |
| `sutun password` | رمز مدیر را تعیین، عوض یا حذف می‌کند. |
| `sutun port` | پورت پنل وب را عوض می‌کند. |
| `sutun ssl` | یک گواهی رایگان از Let's Encrypt می‌گیرد و پنل را به HTTPS می‌برد. |
| `sutun remove-ssl` | پنل را به HTTP ساده برمی‌گرداند. |

## مش

| دستور | کاری که انجام می‌دهد |
| :--- | :--- |
| `sutun join` | با کد دعوت (`xrmesh://…`) به یک مش می‌پیوندد. |
| `sutun invite` | کد دعوت این سرور را نشان می‌دهد. |
| `sutun status` | وضعیت نود، مش و پنل را نشان می‌دهد. |
| `sutun peers` | همتاهای وصل‌شده را با تأخیر زنده نشان می‌دهد. |
| `sutun routes` | جدول مسیریابی مش را نشان می‌دهد. |
| `sutun link-list` | لینک‌های ICMP و PCK را با شمارندهٔ بسته‌هایشان نشان می‌دهد. |
| `sutun link-delete <name>` | یک لینک ICMP یا PCK را حذف می‌کند، مثلاً `out-1234`. |

## تونل‌ها

تونل‌ها در پنل ساخته می‌شوند. این دستورها آن‌ها را نشان می‌دهند، یا همه را متوقف و دوباره راه‌اندازی می‌کنند.

| دستور | کاری که انجام می‌دهد |
| :--- | :--- |
| `sutun tunnels` | تونل‌های ذخیره‌شده را با پورت‌ها و وضعیت سرویسشان نشان می‌دهد. |
| `sutun tunnels-stop` | همهٔ تونل‌ها را متوقف می‌کند و بعد از ری‌استارت سرور هم خاموش نگه می‌دارد. تونل‌های ذخیره‌شده می‌مانند. |
| `sutun tunnels-apply` | تونل‌های ذخیره‌شده را دوباره راه می‌اندازد. |

## سرویس‌ها

| دستور | کاری که انجام می‌دهد |
| :--- | :--- |
| `sutun start` | تنظیمات نود را اعمال می‌کند و همهٔ سرویس‌ها را راه می‌اندازد. |
| `sutun restart` | همهٔ سرویس‌های SuTun را ری‌استارت می‌کند. |
| `sutun stop` | همهٔ سرویس‌های SuTun را متوقف می‌کند. |
| `sutun logs` | لاگ‌های مش و پنل را زنده نشان می‌دهد. برای خروج <kbd>Ctrl</kbd>+<kbd>C</kbd> را بزنید. |
| `sutun self-test` | نصب، سرویس‌ها و اتصال را بررسی می‌کند و مشکل‌ها را گزارش می‌دهد. |

## نگهداری

| دستور | کاری که انجام می‌دهد |
| :--- | :--- |
| `sutun update` | اسکریپت، پنل وب و هستهٔ EasyTier را به‌روز می‌کند. |
| `sutun delete` | تنظیمات مش این نود را حذف می‌کند. برنامه‌های نصب‌شده می‌مانند. |
| `sutun uninstall` | SuTun را کامل حذف می‌کند: سرویس‌ها، تنظیمات و برنامه‌ها. |
| `sutun version` | نسخهٔ نصب‌شده را نشان می‌دهد. |
| `sutun help` | فهرست دستورها را نشان می‌دهد. |

:::danger[delete و uninstall برگشت‌پذیر نیستند]
`delete` این سرور را از مش خارج می‌کند. `uninstall` پنل، تونل‌ها و همهٔ تنظیمات را هم پاک
می‌کند. برای تأیید باید `DELETE` یا `REMOVE` را تایپ کنید.
:::
