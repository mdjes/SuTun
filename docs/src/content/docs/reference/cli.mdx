---
title: Terminal commands
description: Every sutun command, grouped by what you use it for.
---

Run `sutun` with no arguments to open the interactive terminal menu. Every command below also
works on its own, which is handy for scripts. Most of them change the system, so run them as `root`
or with `sudo`.

:::tip
The web panel is where you manage the mesh day to day. The terminal is for setup, and for getting
back into the panel when something goes wrong.
:::

## Panel access

| Command | What it does |
| :--- | :--- |
| `sutun token` | Print a new one-time login link, valid for 60 minutes. |
| `sutun password` | Set, change or remove the admin password. |
| `sutun port` | Change the web panel port. |
| `sutun ssl` | Get a free Let's Encrypt certificate and switch the panel to HTTPS. |
| `sutun remove-ssl` | Switch the panel back to plain HTTP. |

## Mesh

| Command | What it does |
| :--- | :--- |
| `sutun join` | Join a mesh with an invite code (`xrmesh://…`). |
| `sutun invite` | Show this server's invite code. |
| `sutun status` | Show node, mesh and panel status. |
| `sutun peers` | List connected peers with live latency. |
| `sutun routes` | Show the mesh routing table. |
| `sutun link-list` | List ICMP and PCK links with their packet counters. |
| `sutun link-delete <name>` | Delete one ICMP or PCK link, e.g. `out-1234`. |

## Tunnels

Tunnels are created in the panel. These commands list them, and stop or restart all of them.

| Command | What it does |
| :--- | :--- |
| `sutun tunnels` | List saved tunnels with their ports and service state. |
| `sutun tunnels-stop` | Stop every tunnel and keep them off after a reboot. The saved tunnels stay. |
| `sutun tunnels-apply` | Start the saved tunnels again. |

## Services

| Command | What it does |
| :--- | :--- |
| `sutun start` | Apply the node config and start every service. |
| `sutun restart` | Restart every SuTun service. |
| `sutun stop` | Stop every SuTun service. |
| `sutun logs` | Follow the mesh and panel logs live. Press <kbd>Ctrl</kbd>+<kbd>C</kbd> to stop. |
| `sutun self-test` | Check the install, services and connectivity, and report problems. |

## Maintenance

| Command | What it does |
| :--- | :--- |
| `sutun update` | Update the script, the web panel and the EasyTier core. |
| `sutun delete` | Delete this node's mesh config. Installed programs stay. |
| `sutun uninstall` | Remove SuTun completely: services, config and programs. |
| `sutun version` | Print the installed version. |
| `sutun help` | Print the command list. |

:::danger[delete and uninstall can't be undone]
`delete` removes this server from the mesh. `uninstall` also removes the panel, tunnels and every
setting. You confirm by typing `DELETE` or `REMOVE`.
:::
